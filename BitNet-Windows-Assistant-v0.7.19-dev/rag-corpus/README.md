# Dossier RAG — support utilisateur
Place ici les fichiers PDF / TXT / MD que tu veux indexer et poser comme *sources de référence*.

## Usage dans l'application
1. Ouvrir BitNet Windows Assistant
2. Cliquer `＋ Joindre PDF / image / texte`
3. Sélectionner les fichiers de ce dossier
4. Cliquer `Indexer les documents`
5. Activer `Utiliser le RAG`
6. Poser une question liée au contenu

## Règles
- Les fichiers sont restés à cet endroit : l'index n'y touche pas.
- `Indexation terminée` conserve une base locale séparée.
- Suppression d'une source : retirer le fichier ou la source de l'index.

## A noter
- Ne jamais vérouiller la connexion `BitNet-runtime`, il reste à l'extérieur.
- La base documentaire interne (default RAG) peut remplir le trou si lecture absente.
